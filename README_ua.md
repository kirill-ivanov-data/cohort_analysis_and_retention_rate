# Когортний аналіз та Retention Rate (Python)

[Read in English](README.md)

Цей проєкт з продуктової аналітики, присвячений когортному аналізу та розрахунку Retention Rate. 
Суть проекту полягає в тому, щоб розділити користувачів на групи за місяцем здійснення ключової дії та розрахувати, який відсоток від початкової групи залишається в кожному з наступних місяців. 
Такий аналіз дозволяє порівнювати різні стани продукту та оцінювати якісь зміни сприяють або перешкоджають утриманню користувачів.

### 🛠 Стек технологій
* **Мова:** Python
* **Бібліотеки:** pandas, numpy (робота з даними), seaborn, matplotlib (візуалізація)

### Файли в репозиторії
* cohort_analysis.ipynb — файл з кодом, покроковим описом логіки та фінальною візуалізацією (Heatmap).
